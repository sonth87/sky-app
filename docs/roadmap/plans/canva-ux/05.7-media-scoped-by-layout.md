# GĐ14.7 — Panel + Modal Media: tách "Trong layout" / "Toàn bộ"

> **CHỐT LẠI LẦN 2 (2026-08-06):** Bản trước tách "Media" (app cung cấp, placeholder rỗng) vs
> "Cá nhân" — Sonth phản hồi: **bỏ hẳn khái niệm "mẫu do tôi cung cấp" cho Media**, quay lại tách
> theo **"Trong layout hiện tại" vs "Toàn bộ"** (đúng ý tưởng đã làm ở bản ĐẦU TIÊN của file này,
> trước khi bị sửa nhầm sang hướng "Media/Cá nhân" ở lần trước). Bản này khôi phục lại hướng đó,
> viết đầy đủ cả PANEL và MODAL (bản đầu tiên chỉ áp cho panel + modal rời rạc, chưa nhất quán).

## Bối cảnh

**Media KHÁC "Mẫu"** — "Mẫu" (Templates) giữ nguyên 2 tab "Mẫu"(app cung cấp)/"Cá nhân" (GĐ18/19,
KHÔNG đổi). Còn "Media" (ảnh) tách theo chiều khác: **"Trong layout hiện tại"** (ảnh ĐANG ĐƯỢC
DÙNG ở document đang mở — tính bằng cách quét `variant.items`/background của TOÀN BỘ variant
trong document) vs **"Toàn bộ"** (mọi ảnh đã upload, xuyên MỌI layout, KHÔNG lọc).

**Phạm vi "layout hiện tại" — đã chốt trước đó (AskUserQuestion):** toàn bộ document (mọi variant
tỷ lệ khung hình 16:9/9:16/1:1... của layout đang mở), KHÔNG chỉ variant đang xem trên
`VariantTabs`.

## Hàm thuần — `collectUsedAssetPaths`

Đặt tại `packages/slide-shared/src/layout/asset-usage.ts` (file mới) — tái dùng ĐÚNG pattern đã
có ở `preload.ts`'s `collectLayoutImagePaths`/`collectImageVarKeys` (duyệt mọi variant + đệ quy
`LoopItem.itemTemplate`), nhưng thu thập theo **`src` TĨNH** (ảnh đã gán cứng), KHÁC
`collectLayoutImagePaths` (đó là theo `varKey` + 1 record cụ thể, dùng cho preload runtime — 2
mục đích khác nhau, KHÔNG gộp chung 1 hàm).

```ts
// packages/slide-shared/src/layout/asset-usage.ts
import type { LayoutContent, LayoutItem } from './types.js';

function collectItemAssetPaths(items: LayoutItem[], out: Set<string>): void {
  for (const item of items) {
    if (item.type === 'image' && item.src) out.add(item.src);
    if (item.type === 'loop') collectItemAssetPaths(item.itemTemplate, out);
    // GalleryItem (nếu GĐ14.6 đã làm) — mảng ảnh riêng, không phải itemTemplate:
    if (item.type === 'gallery') {
      for (const img of item.images) if (img.src) out.add(img.src);
    }
  }
}

/** Toàn bộ relativePath ảnh ĐANG DÙNG (gán src tĩnh) trong TẤT CẢ variant của 1 document — dùng
 * để lọc Media panel/modal theo "layout hiện tại" (GĐ14.7). Ảnh chỉ bind qua `varKey` (chưa gán
 * src cụ thể) KHÔNG tính — varKey là "chỗ trống chờ dữ liệu", không tham chiếu 1 asset cụ thể ở
 * THỜI ĐIỂM THIẾT KẾ. */
export function collectUsedAssetPaths(doc: LayoutContent): string[] {
  const paths = new Set<string>();
  for (const variant of doc.variants) {
    if (variant.background?.kind === 'image' && variant.background.src) paths.add(variant.background.src);
    collectItemAssetPaths(variant.items, paths);
  }
  return [...paths];
}
```

## `ImagePanel.tsx` — 2 tab "Trong layout" / "Toàn bộ"

`ImagePanel` ĐÃ nhận `editor: Editor` — tự lấy `doc` qua `useEditorState`, KHÔNG cần Flyout
truyền thêm prop mới cho phần lọc. Đổi `listAssets`/`resolveAssetUrl`/`deleteAsset` rời rạc hiện
tại thành nhận `assetPort?: AssetPort` gộp (cần vì mở `MediaLibraryModal` đầy đủ cần cả
`saveImageBlob` — `ImagePanel` hiện KHÔNG có field này; giống bước gộp đã làm cho
`ImageControls`/`FrameBackgroundControls` từ GĐ14).

```tsx
export function ImagePanel({ editor, variant, loopItemId, assetPort }: ImagePanelProps) {
  const doc = useEditorState(editor, (s) => s.doc);
  const usedPaths = useMemo(() => new Set(collectUsedAssetPaths(doc)), [doc]);

  const [activeTab, setActiveTab] = useState<'current' | 'all'>('current'); // mặc định "Trong
                                                                                // layout" — liên
                                                                                // quan trực tiếp
                                                                                // nhất tới việc
                                                                                // đang thiết kế
  const [assets, setAssets] = useState<AssetMeta[] | null>(null);
  const [modalOpen, setModalOpen] = useState<'library' | 'upload' | false>(false);

  useEffect(() => {
    if (!assetPort) return;
    assetPort.listAssets().then(setAssets);
  }, [assetPort]);

  const currentAssets = (assets ?? []).filter((a) => usedPaths.has(a.relativePath));
  const allAssets = (assets ?? []).slice(0, 20); // "Toàn bộ" tab trên PANEL giới hạn 20 gần nhất

  return (
    <>
      <div className="px-[15px] pt-[15px] pb-[10px] flex items-center justify-between">
        <span className="font-bold text-[13px]">Media</span>
        {assetPort && (
          <button onClick={() => setModalOpen('upload')} title="Thêm ảnh" className="w-6 h-6 flex items-center justify-center rounded-[7px] hover:bg-[#f4f5f9] text-[#5c5d6e]">
            <Plus size={16} />
          </button>
        )}
      </div>

      <Tabs value={activeTab} onValueChange={(v) => setActiveTab(v as typeof activeTab)}>
        <TabsList className="px-[15px]">
          <TabsTrigger value="current">Trong layout{currentAssets.length > 0 ? ` (${currentAssets.length})` : ''}</TabsTrigger>
          <TabsTrigger value="all">Toàn bộ</TabsTrigger>
        </TabsList>

        <TabsContent value="current">
          {currentAssets.length === 0 ? (
            <div className="px-[14px] text-[11px] text-[#9a9bab] text-center py-6">
              Layout này chưa dùng ảnh nào — bấm <strong>+</strong> hoặc chuyển tab "Toàn bộ" để chọn ảnh có sẵn.
            </div>
          ) : (
            <div className="p-[8px_14px] grid grid-cols-2 gap-2 overflow-y-auto">
              {currentAssets.map((asset) => (
                <AssetThumbnail key={asset.relativePath} asset={asset} resolveAssetUrl={assetPort?.resolveAssetUrl} onClick={() => handlePick(asset)} onDelete={assetPort?.deleteAsset} />
              ))}
            </div>
          )}
        </TabsContent>

        <TabsContent value="all">
          {!assetPort ? (
            <div className="px-[14px] text-[11px] text-[#9a9bab]">Chưa nối AssetPort.</div>
          ) : allAssets.length === 0 ? (
            <div className="px-[14px] text-[11px] text-[#9a9bab] text-center py-6">Chưa có ảnh nào.</div>
          ) : (
            <>
              <div className="p-[8px_14px] grid grid-cols-2 gap-2 overflow-y-auto">
                {allAssets.map((asset) => (
                  <AssetThumbnail key={asset.relativePath} asset={asset} resolveAssetUrl={assetPort.resolveAssetUrl} onClick={() => handlePick(asset)} onDelete={assetPort.deleteAsset} />
                ))}
              </div>
              {(assets?.length ?? 0) > 20 && (
                <div className="p-[8px_14px]">
                  <button onClick={() => setModalOpen('library')} className="w-full py-2 text-[11.5px] font-semibold rounded-lg border border-[#e6e6ee] hover:bg-[#f4f5f9] text-[#5c5d6e]">
                    Xem thêm ({assets!.length - 20} ảnh nữa)
                  </button>
                </div>
              )}
            </>
          )}
        </TabsContent>
      </Tabs>

      <MediaLibraryModal
        open={modalOpen !== false}
        onOpenChange={(o) => !o && setModalOpen(false)}
        assetPort={assetPort}
        usedAssetPaths={[...usedPaths]}
        initialTab={modalOpen === 'library' || modalOpen === 'upload' ? modalOpen : undefined}
        onSelect={(relativePath) => handlePick({ relativePath } as AssetMeta)}
      />
    </>
  );
}
```

**`handlePick` GIỮ NGUYÊN 100%** — logic "gán vào item đang chọn nếu là ImageItem, không thì tạo
item mới" đã đúng từ trước, không đổi gì ở đây.

**Bỏ ô search khỏi panel** — panel giờ có 2 view đủ hẹp (Trong layout thường vài ảnh, Toàn bộ cap
20) để lướt mắt bằng thumbnail; search thật cần thiết chỉ khi mở modal (đã có sẵn từ GĐ14).

## `MediaLibraryModal.tsx` — thêm tab "Trong layout" + prop `usedAssetPaths`/`initialTab`

```tsx
export interface MediaLibraryModalProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  assetPort?: AssetPort;
  onSelect: (relativePath: string) => void;
  /** relativePath ảnh ĐANG DÙNG trong layout hiện tại (từ `collectUsedAssetPaths`) — dùng để
   * tab "Trong layout" lọc. Bỏ trống = tab hiện rỗng (fail-soft). */
  usedAssetPaths?: string[];
  /** Tab mở mặc định — do nơi gọi quyết định. Bỏ trống = hành vi cũ GĐ14 (rỗng→'upload', có
   * ảnh→'library'). */
  initialTab?: 'current' | 'library' | 'upload';
}
```

**Đổi tên tab** "Thư viện" → **"Toàn bộ"** (khớp panel). **Thêm tab MỚI "Trong layout"** — đặt
ĐẦU TIÊN (ngữ cảnh mở từ panel luôn liên quan layout hiện tại trước):

```tsx
<TabsList>
  <TabsTrigger value="current">Trong layout{usedAssetPaths && usedAssetPaths.length > 0 ? ` (${usedAssetPaths.length})` : ''}</TabsTrigger>
  <TabsTrigger value="library">Toàn bộ</TabsTrigger>
  <TabsTrigger value="upload">Tải lên</TabsTrigger>
</TabsList>
```

Tách phần render grid (hiện viết trực tiếp trong `TabsContent value="library"`) thành 1 component
con `AssetGrid({ assets, selectedAsset, onSelect, onDelete })` dùng lại cho CẢ 2 tab "Trong
layout"/"Toàn bộ" — tránh trùng lặp JSX. Tab "Trong layout" = `AssetGrid` với
`assets.filter(a => usedSet.has(a.relativePath))`; tab "Toàn bộ" = `AssetGrid` với `assets` đầy
đủ (có search, giữ nguyên).

**Logic default tab:**
```tsx
useEffect(() => {
  if (!open || !assetPort) return;
  assetPort.listAssets().then((list) => {
    setAssets(list);
    setSelectedAsset(null);
    if (initialTab) setActiveTab(initialTab);
    else setActiveTab(list.length > 0 ? 'library' : 'upload'); // hành vi cũ GĐ14
  });
}, [open, assetPort, initialTab]);
```

## Điểm dùng cũ

- `ImageControls.tsx`/`FrameBackgroundControls.tsx` (Property Panel) — nút "Thư viện" mở modal
  với `initialTab: 'library'` (="Toàn bộ", giữ hành vi cũ GĐ14 — đang chọn ảnh cho 1 item cụ thể,
  "Toàn bộ" hợp lý hơn "Trong layout" làm mặc định ở ngữ cảnh này). Cần truyền thêm
  `usedAssetPaths` xuống 2 Controls này (tính 1 lần ở `PropertyPanel.tsx`, nơi ĐÃ có `doc`) để
  tab "Trong layout" của modal hoạt động đúng dù mở từ đây.

## Xoá ảnh trong tab "Trong layout"/"Toàn bộ" — rủi ro CẦN GHI RÕ

`deleteAsset(relativePath)` xoá THẲNG khỏi thư viện toàn cục (file vật lý GC sau) — hành vi GIỮ
NGUYÊN ở CẢ 2 tab (sky-app hiện KHÔNG track "asset X dùng ở layout nào" xuyên toàn bộ DB, chỉ
tính được usage của 1 document đang mở trong RAM qua `collectUsedAssetPaths`). Hệ quả: xoá ảnh từ
tab "Trong layout" của layout A, nếu ảnh đó CŨNG dùng ở layout B (asset dùng chung, VD logo
trường) → layout B mất ảnh (fallback `fallbackText`), KHÔNG cảnh báo trước. Xử lý v1: thêm dòng
chú thích nhỏ trong tab "Trong layout":
```tsx
<div className="px-4 pb-2 text-[10px] text-[#9a9bab]">
  Xoá ảnh ở đây xoá khỏi TOÀN BỘ thư viện, có thể ảnh hưởng layout khác dùng chung ảnh này.
</div>
```
**Backlog thật** (không làm trong GĐ14.7): global asset-usage index (bảng DB ghi asset nào dùng
ở layout nào) để cảnh báo chính xác "đang dùng ở N layout khác" trước khi xoá.

## Vấn đề phát sinh & cách xử lý

- **`ImagePanel`'s prop signature đổi** (3 field rời → 1 `assetPort`) — breaking NỘI BỘ module
  (`Flyout.tsx`), KHÔNG breaking `LayoutDesignerAppProps` public.
- **`usedAssetPaths` tính lại mỗi khi `doc` đổi** — `useMemo` phụ thuộc `[doc]`, đúng lúc, không
  stale. Chi phí duyệt cây item — chấp nhận được (vài chục item, không cần tối ưu sâu hơn).
- **Ảnh dùng qua `varKey`** — KHÔNG xuất hiện ở tab "Trong layout" (đã giải thích ở hàm
  `collectUsedAssetPaths`) — ĐÚNG THIẾT KẾ, không phải thiếu sót.
- **Panel's tab "Toàn bộ" cap 20** — dùng ĐÚNG mốc 20 (khớp yêu cầu Sonth, không phải 12 như bản
  GĐ14 gốc đề xuất trước đây).
