# GĐ14.6 — GalleryItem: khối chứa N ảnh, quản lý bộ ảnh (reorder/replace/caption)

## Bối cảnh

Sau khi audit `GalleryMediaManager.tsx` (my-builder, 375 dòng) — my-builder có 1 dialog RIÊNG để
quản lý **1 bộ ảnh như 1 khối thống nhất** (khác Media Library — chọn 1 ảnh): Add Media,
drag-to-reorder, Replace/Title/Description/Link per-ảnh, Remove.

Sky-app KHÔNG có khái niệm tương đương. GĐ17 (Grid presets) chỉ spawn N `ImageItem` **độc lập**
lên canvas 1 lần — sau đó mỗi ảnh là item riêng, KHÔNG quản lý được như 1 bộ (không reorder giữ
nguyên bố cục, không replace-tại-chỗ, không caption chung). Chọn hướng: thêm `GalleryItem` — 1
LayoutItem type MỚI giữ mảng ảnh + metadata, có modal quản lý riêng (mirror
`GalleryMediaManager.tsx`), khác kiến trúc với GĐ17 (items độc lập) và LoopItem (data-bound theo
CanonicalGroup.members — GalleryItem KHÔNG data-bound, là nội dung TĨNH tự chọn tay, cùng nhóm
với ImageItem/TextItem/ShapeItem/RibbonItem).

**Khác biệt rõ với LoopItem** (dễ nhầm vì cả 2 đều "nhiều ô"):
- `LoopItem` — 1 khung THIẾT KẾ 1 lần, tự LẶP LẠI theo `CanonicalGroup.members` (data-bound, số
  ô = số thành viên nhóm, KHÔNG tự chọn tay).
- `GalleryItem` — N ảnh TỰ CHỌN TAY (như chọn ảnh cho 1 slide "Kỷ niệm"/"Hoạt động"), số ô = số
  ảnh user thêm, KHÔNG liên quan CanonicalGroup.

**Bỏ "Link URL" của my-builder** — my-builder là landing page web (click-through có ý nghĩa),
sky-app hiển thị LED tại lễ (không có tương tác click) → field `link` KHÔNG áp dụng, bỏ hẳn.
**Giữ "Caption"** (đổi tên từ Title/Description gộp 1 field) — có thể dùng làm chú thích hiện
dưới ảnh (VD tên hoạt động), optional, tắt qua `showCaption`.

## Field mới — `packages/slide-shared/src/layout/types.ts`

```ts
export interface GalleryImageEntry {
  id: string; // ổn định trong phạm vi 1 GalleryItem — dùng làm key React + target reorder/remove
  src?: string; // asset relativePath, giống ImageItem.src — GalleryItem KHÔNG có varKey (không
                // data-bind, khác ImageItem có thể bind biến)
  caption?: string; // optional, hiện dưới ảnh nếu showCaption=true
  focalX?: number; // 0..1, mặc định 0.5 — giống ImageItem, áp dụng khi fit='cover'
  focalY?: number;
}

export interface GalleryItem extends BaseItem {
  type: 'gallery';
  images: GalleryImageEntry[];
  layout: 'grid' | 'row' | 'column'; // cách dàn — cùng khái niệm LoopItem.direction, KHÔNG dùng
                                       // lại tên field (LoopItem đã có direction, GalleryItem
                                       // đặt tên riêng 'layout' để tránh nhầm 2 khái niệm)
  columns?: number; // dùng khi layout='grid'
  gap?: number; // px trên canvas chuẩn
  fit: 'cover' | 'contain'; // áp dụng CHUNG cho mọi ảnh trong bộ (không set riêng từng ảnh —
                             // đơn giản hoá, giống my-builder GalleryPro's 1 fit cho toàn gallery)
  showCaption: boolean;
}

// Union LayoutItem — thêm GalleryItem
export type LayoutItem = TextItem | ImageItem | ShapeItem | RibbonItem | LoopItem | GalleryItem;
```

**KHÔNG thêm field `link`** (đã giải thích ở Bối cảnh). **KHÔNG thêm `varKey` per-ảnh** — nếu cần
data-bind ảnh theo record, dùng `LoopItem` (đã có), không lai 2 khái niệm vào 1 type.

### `packages/slide-shared/src/layout/renderer.tsx` — `GalleryItemView` mới

```tsx
export function GalleryItemView({ item, scaleX, scaleY, resolveAssetUrl }: {
  item: GalleryItem; scaleX: number; scaleY: number; resolveAssetUrl?: (path: string) => Promise<string>;
}) {
  const gridStyle: CSSProperties = item.layout === 'grid'
    ? { display: 'grid', gridTemplateColumns: `repeat(${item.columns ?? 3}, 1fr)`, gap: (item.gap ?? 8) * Math.min(scaleX, scaleY) }
    : { display: 'flex', flexDirection: item.layout === 'row' ? 'row' : 'column', gap: (item.gap ?? 8) * Math.min(scaleX, scaleY) };

  if (item.images.length === 0) {
    return (
      <div style={{ width: '100%', height: '100%', display: 'flex', alignItems: 'center', justifyContent: 'center', color: '#7c7c8c', fontSize: 12, background: 'repeating-linear-gradient(45deg,#c9c9d6 0 8px,#e4e4ee 8px 16px)' }}>
        Bộ ảnh trống
      </div>
    );
  }

  return (
    <div style={{ width: '100%', height: '100%', ...gridStyle }}>
      {item.images.map((img) => (
        <GalleryImageCell key={img.id} entry={img} fit={item.fit} showCaption={item.showCaption} resolveAssetUrl={resolveAssetUrl} />
      ))}
    </div>
  );
}

function GalleryImageCell({ entry, fit, showCaption, resolveAssetUrl }: {
  entry: GalleryImageEntry; fit: 'cover' | 'contain'; showCaption: boolean; resolveAssetUrl?: (path: string) => Promise<string>;
}) {
  const resolvedUrl = useResolvedAssetUrl(entry.src, resolveAssetUrl); // hook dùng chung đã có
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: 4 }}>
      <div style={{
        aspectRatio: '1', // ô vuông cố định — v1 KHÔNG cho tuỳ biến tỷ lệ từng ô (đơn giản hoá,
                            // giống ImageItem mặc định vuông lúc mới tạo)
        background: resolvedUrl
          ? `${entry.focalX ?? 0.5} ${entry.focalY ?? 0.5}/${fit} url(${resolvedUrl})`
          : 'repeating-linear-gradient(45deg,#c9c9d6 0 8px,#e4e4ee 8px 16px)',
        borderRadius: 4,
      }} />
      {showCaption && entry.caption && (
        <div style={{ fontSize: 11, color: '#5c5d6e', textAlign: 'center' }}>{entry.caption}</div>
      )}
    </div>
  );
}
```

## Undo/redo

Mọi mutation trong `GalleryManagerModal` (add/reorder/replace/remove/caption) dispatch
`patchItemCommand<GalleryItem>(variant.aspect.id, item.id, item, { images: newImages }, loopItemId)`
NGAY LẬP TỨC mỗi lần đổi (mirror my-builder's "All mutations dispatch immediately (undo/redo via
UPDATE_PROPS)") — nghĩa là mở modal, kéo sắp xếp 3 lần, đóng modal → history có 3 bước undo riêng
(KHÔNG gộp thành 1 command khi đóng modal, đơn giản hoá, nhất quán "mỗi thay đổi field = 1
patchItemCommand" đã áp dụng toàn bộ Property Panel).

## Vấn đề phát sinh & cách xử lý

- **`images[]` rỗng khi mới spawn** — render hiện "Bộ ảnh trống" (đã code ở `GalleryItemView`),
  KHÔNG lỗi, y hệt cách `LoopItem` với `itemTemplate: []` tự ẩn (nhưng Gallery hiện placeholder
  thay vì ẩn — vì Gallery không data-bound, "trống" là trạng thái CHỜ user thêm ảnh, không phải
  "0 members" runtime).
- **Xoá ảnh đang chọn trong modal** — `selectedIndex` phải tự điều chỉnh (giảm 1 nếu xoá ảnh
  trước, về `null` nếu xoá đúng ảnh đang chọn) — copy chính xác logic `removeItem` của
  `GalleryMediaManager.tsx` (dòng 160-168), đã đúng, không thiết kế lại.
- **`aspectRatio: '1'` cố định mỗi ô** — v1 KHÔNG cho tuỳ biến tỷ lệ từng ô riêng (đơn giản hoá).
  Nếu Sonth cần ô chữ nhật/tỷ lệ khác sau này, thêm field `aspectRatio?: number` per-entry —
  KHÔNG làm trước khi có nhu cầu thật.
- **`focalX`/`focalY` per-ảnh** — CÓ trong `GalleryImageEntry` (đã ghi ở field mới) nhưng
  Property Panel/Modal v1 KHÔNG có UI chỉnh (không có slider focal point trong
  `GalleryManagerModal`) — field tồn tại cho tương lai (VD tái dùng `FocalPointControl` đã có ở
  GĐ8b nếu Sonth muốn thêm sau), v1 chỉ dùng default 0.5/0.5.
